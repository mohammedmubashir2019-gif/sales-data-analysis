# Sales Data Analysis Project

This project analyzes retail sales data using Python.

## Tools Used
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Total Sales Calculation
- Sales by Category
- Top 10 Cities by Sales
- Profit by Category

## Key Insights
- Technology category has highest sales and profit
- New York City generates highest revenue
- Office Supplies contributes significantly

## Files
- sales_analysis.ipynb → main analysis notebook
- SampleSuperstore.csv → dataset
