# Sales Data Analysis Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data using Python.  
The analysis helps identify sales trends, profitable product categories, and high-performing cities through data visualization and business insights.

---

## Objectives
- Analyze overall sales performance
- Identify top-performing product categories
- Discover cities generating the highest revenue
- Evaluate profit distribution across categories
- Visualize insights using charts and graphs

---

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook / Google Colab

---

## Skills Demonstrated
- Data Analysis
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insight Generation
- Python Programming

---

## Dataset Information
The dataset contains retail sales information including:
- Sales
- Profit
- Product Categories
- Customer Segments
- Cities and Regions
- Quantity Ordered

Dataset used:
`SampleSuperstore.csv`

---

## Analysis Performed

### 1. Total Sales Analysis
Calculated the total revenue generated from all sales transactions.

### 2. Sales by Category
Compared sales performance across different product categories.

### 3. Top 10 Cities by Sales
Identified the highest revenue-generating cities.

### 4. Profit by Category
Analyzed which categories generate the highest profits.

### 5. Data Visualization
Created bar charts to visualize trends and insights clearly.

---

## Key Insights
- Technology is the highest-performing category in both sales and profit.
- Office Supplies contribute significantly to total revenue.
- New York City generated the highest sales among all cities.
- Furniture category shows comparatively lower profitability.
- Sales trends can help businesses improve inventory and marketing strategies.

---

## Business Recommendations
- Increase investment in Technology products due to high profitability.
- Improve marketing strategies in top-performing cities like New York and Los Angeles.
- Optimize pricing and discounts for Furniture products to improve profits.
- Focus on customer demand trends to improve future sales performance.
- Use data-driven decision making for inventory management.
