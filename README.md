# Sales Data Analysis Project

This project performs exploratory data analysis (EDA) on retail sales data to uncover trends, patterns, and key business insights using Python.

---

## Project Overview
- Analyze sales performance across different product categories
- Identify top-performing cities by revenue
- Understand profit distribution across categories
- Visualize insights using charts for better decision-making

---

## Tools Used
- Python
- Pandas
- Matplotlib

---

## Skills Demonstrated
- Data Analysis
- Data Visualization
- Python Programming
- Data Cleaning & Exploration

---

## Analysis Performed
- Total Sales Calculation
- Sales by Category
- Top 10 Cities by Sales
- Profit by Category

---



## Key Insights
- The Technology category generates the highest sales and profit
- New York City is the top-performing city by revenue
- Office Supplies contribute significantly to overall sales

---

## How to Run
1. Open the notebook in Google Colab
2. Upload the dataset (SampleSuperstore.csv)
3. Run all cells to see the analysis and visualizations

---

## Files
- `sales_analysis.ipynb` → Main analysis notebook  
- `SampleSuperstore.csv` → Dataset
